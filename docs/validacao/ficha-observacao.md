# Ficha de observação — modelo

> Uma cópia impressa por rodada. O condutor preenche à mão durante a sessão; os
> resultados REAIS depois são registrados em `docs/validacao/rodada-N.md` (uma cópia
> deste modelo, preenchida — nunca com números inventados).

```

| Tarefa | Concluiu (S/N) | Tempo (s) | Meta (s) | Erros/cliques sem efeito | Ajuda (0/1/2) | Observações do condutor | Falas da participante |
|---|---|---|---|---|---|---|---|

Decisão (Aceito / Aceito com ajustes / Não aceito): ________
Problemas encontrados → issue #: ________
Mudanças feitas depois (PRs): ________
```

## Lembretes para o condutor

- Cronômetro: inicia quando ela termina de ler a tarefa, para quando o resultado
  esperado aparece na tela. Pedido de esclarecimento não pausa a contagem.
- Ajuda: nível 0 = nenhuma; nível 1 = dica geral; nível 2 = indicar onde olhar. Anote
  todo nível de ajuda dado, mesmo pequeno.
- Critérios de aceite e a regra de decisão (Aceito / Aceito com ajustes / Não aceito)
  estão na seção 5 de `docs/VALIDACAO.md`.
